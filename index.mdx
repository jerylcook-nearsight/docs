Nearsight is vendor-neutral spatial intelligence built for AI agents. It takes live positions from any tracking source and any kind of asset (vehicles, equipment, devices, people, shipments) and turns them into something Claude, ChatGPT, or any MCP-capable agent can reason over: where it is, where it's been, and what happened nearby.

Nearsight isn't tied to a tracking vendor. If a system can make an HTTP request, it can send positions: GPS trackers, IoT devices, or the tracking platform you already run. Mixed fleets and assets that aren't vehicles all land in one place.

There are two ways in:

- **The REST API** sends data to Nearsight: asset positions and geofences, from any source.
- **The MCP server** lets your AI assistant or agent ask questions about that data in plain language.

## Make your first call

<Steps>
  <Step title="Get an API key">
    Sign up at [nearsight.ai](https://nearsight.ai). Your key arrives by email with a link to reveal it.
  </Step>
  <Step title="Send the key with every request">
    Pass it in the `X-API-Key` header. The base URL for all endpoints is `https://api.nearsight.ai/api`.
  </Step>
  <Step title="Check that it works">
    List your geofences. A new account returns an empty list.

    ```bash
    curl https://api.nearsight.ai/api/v1/geo \
      -H "X-API-Key: YOUR_API_KEY"
    ```
  </Step>
</Steps>

## Connect your AI assistant

Nearsight speaks MCP, the open standard for connecting agents to tools. Add it once and sign in with your Nearsight account when prompted.

**Server URL:** `https://mcp.nearsight.ai/mcp`

<Tabs>
  <Tab title="Claude">
    1. Open **Settings → Connectors**.
    2. Click **Add custom connector**.
    3. Name it **Nearsight** and paste the server URL.
    4. Click **Add**, then **Connect**, and sign in with your Nearsight account.

    Custom connectors require a paid Claude plan.
  </Tab>
  <Tab title="ChatGPT">
    1. Open **Settings → Apps & Connectors**.
    2. Under **Advanced**, turn on **Developer mode**.
    3. Click **Create**, name it **Nearsight**, paste the server URL, and choose **OAuth**.
    4. Sign in with your Nearsight account when prompted.

    Requires ChatGPT Plus, Pro, Business, or Enterprise.
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http nearsight https://mcp.nearsight.ai/mcp
    ```

    Any client that supports MCP over Streamable HTTP with OAuth works the same way.
  </Tab>
</Tabs>

Once connected, ask things like "which assets passed within 500 meters of the depot in the last hour?" or "show the trajectory of the five fastest assets today."

## Nearsight Agents

<Note>
  Nearsight Agents are in development and not available yet. This section describes what's coming.
</Note>

Asking questions is one half. The other half is not having to ask. Nearsight Agents are always-on agents that run on Nearsight's side, on the same spatial tools your assistant uses. There is nothing to install: you set rules and switch them on.

- **Exception watchdog (in development).** Set rules for dwell, stale telemetry, and zone entry or exit. When a rule trips, the agent pulls the trajectory, checks what was nearby, and emails a plain-language explanation with the evidence, a likely cause, and a map.
- **Incident impact (in development).** Give the agent an area, or let a weather alert define one. It reports which assets are inside, approaching, or just left.
- **Agent-to-agent, A2A (planned).** Your own dispatch, support, or planning agents will be able to hand a Nearsight agent a task, such as investigating an asset or checking what's affected in an area.
