title: "Quickstart"
description: "Create a geofence and send your first asset position"
---

This walkthrough creates a geofence, sends one position for an asset, and confirms both landed. You need an API key first; see [Authentication](/authentication).

Set your key once so the examples run as written:

```bash
export NEARSIGHT_API_KEY="YOUR_API_KEY"
```

<Steps>
  <Step title="Create a geofence">
    Define a circle from a center point and a radius in meters.

    ```bash
    curl -X POST https://api.nearsight.ai/api/v1/geo/radius \
      -H "X-API-Key: $NEARSIGHT_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "name": "Depot North",
        "description": "Overnight parking yard",
        "latitude": 38.9072,
        "longitude": -77.0369,
        "radiusInMeters": 500
      }'
    ```

    `name`, `latitude`, `longitude`, and `radiusInMeters` are required. You can also create fences [from WKT](/api-reference/geo-fences/create-a-geofence-from-wkt) or [import GeoJSON](/api-reference/geo-fences/import-geofences-from-a-geojson-featurecollection).
  </Step>

  <Step title="Send an asset position">
    Report where an asset is right now.

    ```bash
    curl -X POST https://api.nearsight.ai/api/v1/assets/track \
      -H "X-API-Key: $NEARSIGHT_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "name": "7145",
        "type": "metrobus",
        "timestamp": 1748224800000,
        "latitude": 38.9072,
        "longitude": -77.0369,
        "bearing": 274.5,
        "speed": 42.3,
        "status": "IN_SERVICE"
      }'
    ```

    | Field | Required | Notes |
    | ----- | -------- | ----- |
    | `name` | Yes | The asset's unique identifier within its fleet. |
    | `type` | Yes | The asset's classification. It must match a type that exists for your account. |
    | `timestamp` | Yes | GPS fix time from the device, in Unix epoch milliseconds (UTC). Not the time you send the request. |
    | `latitude`, `longitude` | Yes | WGS-84 decimal degrees. |
    | `bearing` | No | Direction of travel in degrees, clockwise from true north. |
    | `speed` | No | Speed in km/h. |
    | `status` | No | One of `IN_SERVICE`, `OUT_OF_SERVICE`, `IDLE`, `MAINTENANCE`. |
    | `information` | No | Freeform text or serialized JSON. Stored, not indexed. |

    To send many positions in one call, post an array of the same objects to [the batch endpoint](/api-reference/asset-tracking/ingest-a-batch-of-asset-position-snapshots).
  </Step>

  <Step title="Confirm the geofence exists">
    ```bash
    curl https://api.nearsight.ai/api/v1/geo \
      -H "X-API-Key: $NEARSIGHT_API_KEY"
    ```

    The response lists the name and description of each geofence on your account.
  </Step>

  <Step title="Ask your AI assistant">
    Connect the Nearsight MCP server to Claude or ChatGPT ([setup steps](/#connect-your-ai-assistant)), then ask about the data you just sent, for example: "Which assets are inside Depot North right now?"
  </Step>
</Steps>
